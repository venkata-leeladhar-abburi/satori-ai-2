# Satori AI — Autonomous Procurement

Satori AI is a premium enterprise SaaS landing page for an AI-powered procurement platform.

## Features
- **Autonomous Workflows:** End-to-end procurement orchestration.
- **Supplier Intelligence:** Real-time risk and performance monitoring.
- **Enterprise Integrations:** Seamless connection with SAP, Oracle, AWS, and more.
- **Premium Design:** Modern, cinematic UI with smooth scroll animations.

## Tech Stack
- React 19
- Tailwind CSS 4
- Lucide React Icons
- Vite

## Getting Started
```bash
npm install
npm run dev
```
